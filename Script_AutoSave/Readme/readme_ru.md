Этот плагин решает проблему, автоматически сохраняя данные в фоновом режиме, но разумно.

Подробнее:
- По умолчанию плагин сохраняет данные каждые 10 минут. 
- Не используется ручное быстрое сохранение (F5), а создаются собственные слоты (Autosave_Slot_001–010). Самый старый перезаписан. Ваше собственное сохранение F5 останется в безопасности! 
- Не сохраняется, когда вы находитесь в бою, разговариваете с кем-то или игра находится в фоновом режиме (выключена). 
- Интервал и количество слотов можно легко настроить в INI-файле.
