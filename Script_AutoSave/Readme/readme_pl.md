Ta wtyczka rozwiązuje ten problem, automatycznie tworząc zapisy w tle.

Szczegóły:
- Domyślnie wtyczka tworzy zapis co 10 minut. 
- Nie wykorzystuje ręcznego szybkiego zapisu (F5), lecz tworzy własne sloty (Autosave_Slot_001–010). Najstarszy plik jest nadpisywany. Twoje własne zapisy F5 pozostaną bezpieczne!
- Zapisywanie nie odbywa się, gdy jesteś w walce, rozmawiasz z kimś lub gra działa w tle (jest wyłączona).
- Interwał i liczbę slotów można łatwo skonfigurować w pliku INI.
