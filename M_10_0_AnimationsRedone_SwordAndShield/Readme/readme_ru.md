Набор новых анимаций для движений со щитом и мечом. Каждая анимация была полностью переработана или тщательно скорректирована, чтобы сделать ее более плавной, отзывчивой и естественной по сравнению с оригиналами. Эта доработка охватывает весь набор движений меча и щита: атаки, перемещения, спотыкания и падения.
