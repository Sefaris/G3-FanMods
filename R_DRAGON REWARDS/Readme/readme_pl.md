Aby mod działał poprawnie, należy zainstalować LTM oraz Conquest_Swords&Dragons. Zaleca się również zainstalowanie G3 Armor And Weapon Rebuilt, aby miecze ze smoków wyglądały lepiej i miały inne ikony, tak jak na zrzucie ekranu.

Ten mod dodaje łupy z LTM do ciał smoków, a także wprowadza do sprzedaży u Ingolfa (łowcy smoków z Varantu) nowe zestawy zbroi, miecze i hełmy oraz tarcze z LTM.
