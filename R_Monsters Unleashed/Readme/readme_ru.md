Данная модификация не совместима с модом: CombatAnimationOverhaul_2H

Этот мод является продолжением работы над улучшением анимаций в Gothic 3 и фокусируется на исправлении и обогащении боевых движений самых узнаваемых монстров игры.

Мод включает новые анимации и звуки:
- Дракона
- Гаргульи
- Голема
- Монстра
- Потрошителя
- Стража храма
- Саблезуба
- Зомби
