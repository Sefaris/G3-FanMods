Ten mod stanowi kontynuację prac nad ulepszeniem animacji w grze Gothic 3 i skupia się na poprawianiu oraz wzbogacaniu ruchów bojowych najbardziej rozpoznawalnych potworów w grze.

Mod zawiera nowe animacje i dźwięki:
- Smoka
- Gargulca
- Golema
- Potwora
- Pogromcy
- Strażnika świątyni
- Szablastego
- Zombie
