Modyfikacja animacji, całkowicie zmieniająca styl walki rapierami w Gothic 3. W przypadku rapierów mechanika krwawienia działa w specjalny sposób, umożliwiając wywoływanie efektu krwawienia poprzez zwykłe ciosy.
Mod zawiera nowe animacje:
- Bieg
- Ruchy z blokiem
- Szybkie ataki nie popychają postaci do przodu
- Szybkie ataki
- Mocne ataki
