DialogueSkipper to niewielka wtyczka do gry Gothic 3, która pozwala szybciej pomijać dialogi postaci niezależnych za pomocą skrótu klawiszowego (domyślnie prawy przycisk myszy) oraz, opcjonalnie, wyłączyć animacje okienek napisów i menu dialogowego. Jeśli wybierzesz inny klawisz niż prawy przycisk myszy, aby pomijanie działało, musisz przytrzymać wybrany klawisz i jednocześnie nacisnąć prawy przycisk myszy.
